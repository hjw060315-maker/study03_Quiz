# 상식 퀴즈 (study03_Quiz)

**학번 2601996 이름 황지원**

4지선다 상식 퀴즈 웹 앱입니다. 카테고리 4개(한국사, 세계지리, 과학, 예술과 문화)에 10문제씩, 모두 40문제가 있습니다.

- 배포 주소: https://hjw060315-maker.github.io/study03_Quiz/
- 모드: 연습(틀린 문제 다시 풀기), 스피드(문항마다 15초), 힌트(오답 2개 지우기, 맞히면 0.5점)
- 답을 고르면 곧바로 정답 여부와 한 줄 해설, 출처 링크를 보여 줍니다.

## 실행 방법

서버 없이 `index.html`을 브라우저에서 열면 됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 화면 스타일 |
| `script.js` | 게임 진행, 모드 규칙, 자체 점검 |
| `questions.js` | 문항 40개 |
| `PRD.md` | 요구사항 문서 |
| `IMPL-PLAN.md` | 단계별 구현 계획서 |
| `CLAUDE.md` | 문항 작성 규칙 |
| `실행기록.md` | 진행 상황과 결정 사항 |
